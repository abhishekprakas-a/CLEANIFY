Cleanify brand assets
=====================

Drop these three image files into THIS folder (public/brand/) with these exact
names. The app already references them everywhere (login, sign-up, admin
sidebar, landing nav + footer, PWA install prompt, favicon and app icon).

1. cleanify-wordmark.png
   The "cleanify" wordmark WITH the wavy underline, in DARK text
   (the version on a white/light background). Used on all light surfaces.
   Transparent background preferred; a white background also looks fine because
   these surfaces are white. Suggested height ~120px+ (PNG, any width).

2. cleanify-wordmark-dark.png
   The same wordmark WITH the wavy underline, in LIGHT/mint text
   (the version on a dark background). Used on any dark surface.
   Transparent or dark background. Suggested height ~120px+.

3. cleanify-icon.png
   The rounded square app icon (the "cleanify" tile). Square, 512x512.
   Used for the browser favicon, the installed-app (PWA) icon, and the
   install-prompt tile.

Until these files exist, the wordmark falls back to clean text automatically,
so nothing looks broken.
